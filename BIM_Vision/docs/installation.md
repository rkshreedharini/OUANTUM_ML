# Installation Guide

## Software Requirements

- Python 3.9+
- Visual Studio Code
- Git
- DVC

---

## Project Location

E:\BIM_Vision

---

## Create Virtual Environment

```bash
python -m venv venv
```

Activate:

```bash
venv\Scripts\activate
```

---

## Install DVC

```bash
pip install dvc
```

---

## Initialize Git

```bash
git init
```

---

## Initialize DVC

```bash
dvc init
```

---

## Verify Installation

```bash
python --version
git --version
dvc --version
```
